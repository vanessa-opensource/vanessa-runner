# infobase - Управление информационными базами

Команды `infobase` создают и обновляют информационные базы, выгружают и восстанавливают `.dt`, а также управляют пользователями, расширениями и регламентными заданиями развёрнутой базы.

```bash
vrunner infobase <подкоманда> [опции] [аргументы]
```

Команды `create-user`, `lock-resources`, `scheduled-job` и `extensions` (кроме `create`) выполняются в режиме 1С:Предприятие внешними обработками из каталога `epf/` пакета vanessa-runner. Если `--ibconnection` у них не указана, используется файловая ИБ `build/ib`.

## init

Создаёт информационную базу и загружает в неё конфигурацию и расширения.

```bash
vrunner infobase init [опции]
```

Порядок работы:

1. Без опций СУБД создаётся файловая ИБ: по пути из `--ibconnection /F<путь>` или, если строка подключения не задана, в `build/ib`. Существующий каталог базы удаляется.
2. С `--dbms-type` или строкой подключения `/S<сервер>\<база>` база считается серверной и не создаётся - используется существующая ИБ.
3. Из `--src` загружается конфигурация: каталог исходников (XML или EDT) и `.cf` - с обновлением конфигурации БД, `.dt` - восстановлением базы целиком.
4. Из `--ext` загружаются расширения и применяются к БД одним обновлением; у загруженных расширений выключены безопасный режим и защита от опасных действий.

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--src` | `VRUNNER_SOURCE` | Источник конфигурации: каталог исходников, `.cf` или `.dt`. Синоним `--source` |
| `--ext` | - | Расширение: `.cfe`-файл или каталог исходников; можно указать несколько раз. Имя расширения - из имени файла или каталога |
| `--recursive` | - | Искать источники рекурсивно: в `--src` - конфигурацию (не более одной) и расширения, в `--ext` - только расширения |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [файл настроек](./common-options#файл-настроек).

### Примеры

```bash
# Пустая файловая ИБ в build/ib
vrunner infobase init

# ИБ по указанному пути из CF-файла
vrunner infobase init --src ./build/MyApp.cf --ibconnection /F./tmp-ib --ibcmd

# ИБ из исходников с двумя расширениями (.cfe и каталог исходников)
vrunner infobase init \
  --src ./src \
  --ext ./build/МоёРасширение.cfe \
  --ext ./src-ext/Интеграция \
  --ibconnection /F./tmp-ib

# Конфигурация и расширения найдены рекурсивно в каталоге проекта
vrunner infobase init --src ./project --recursive

# Загрузка в существующую серверную ИБ через ibcmd
vrunner infobase init \
  --src ./build/MyApp.cf \
  --ibconnection "/SMyServer\MyIB" \
  --ibcmd \
  --dbms-type PostgreSQL \
  --dbms-server localhost \
  --dbms-base my_db \
  --dbms-user postgres \
  --dbms-pwd secret
```

## update

Обновляет конфигурацию БД. С `--src` перед обновлением загружает конфигурацию из каталога XML-исходников или `.cf`-файла. Без `--ibconnection` используется файловая ИБ `build/ib`, которая должна уже существовать.

```bash
vrunner infobase update [опции]
```

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--src` | `VRUNNER_SOURCE` | Источник конфигурации: каталог XML-исходников или `.cf`. Синоним `--source` |
| `--target` | - | Что обновлять: `main` - основная конфигурация, `<имя>` - расширение, пусто - основная конфигурация и все расширения |
| `--increment` | - | Инкрементальная загрузка исходников по индексу изменений |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [обновление конфигурации БД](./common-options#обновление-конфигурации-бд), [файл настроек](./common-options#файл-настроек).

### Примеры

```bash
# Обновить конфигурацию БД и все расширения
vrunner infobase update --ibconnection /F./ib

# Загрузить CF и обновить БД с оптимизированной реструктуризацией
vrunner infobase update --src ./build/MyApp.cf --rtype v2 --ibconnection /F./ib

# Обновить только расширение
vrunner infobase update --target МоёРасширение --ibconnection /F./ib
```

## dump-dt

Выгружает информационную базу в файл `.dt`. Опция `--ibconnection` обязательна.

```bash
vrunner infobase dump-dt [опции] <OUT>
```

### Аргументы

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Путь к создаваемому файлу `.dt` (**обязательный**; в файле настроек - ключ `out`) |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [файл настроек](./common-options#файл-настроек).

### Примеры

```bash
vrunner infobase dump-dt --ibconnection /F./ib --v8version 8.3.24 ./backup/MyProject.dt
```

## create-user

Создаёт пользователя информационной базы без пароля. Пользователь создаётся **только если в ИБ ещё нет ни одного пользователя**, иначе команда ничего не делает. Роли, которых нет в конфигурации, пропускаются с предупреждением; если не найдена ни одна - ошибка.

```bash
vrunner infobase create-user [опции] <NAME>
```

### Аргументы

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `NAME` | - | Имя создаваемого пользователя (**обязательный**) |

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--role` | - | Роль пользователя; можно указать несколько раз. По умолчанию `ПолныеПрава`, `АдминистраторСистемы` и, если есть, `ИнтерактивноеОткрытиеВнешнихОтчетовИОбработок` |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд).

### Примеры

```bash
# Администратор с ролями по умолчанию
vrunner infobase create-user --ibconnection /F./ib Администратор

# Пользователь с заданным набором ролей
vrunner infobase create-user --role ЧтениеДанных --role РаботаСЗаказами --ibconnection /F./ib Оператор
```

## lock-resources

Разрешает или запрещает работу с внешними ресурсами (механизм БСП). Укажите ровно один из флагов `--allow` или `--deny`.

```bash
vrunner infobase lock-resources (--allow | --deny) [опции]
```

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--allow` | - | Разрешить работу с внешними ресурсами |
| `--deny` | - | Запретить работу с внешними ресурсами |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд).

### Примеры

```bash
# Запретить внешние ресурсы на копии базы, чтобы она не слала письма и обмены
vrunner infobase lock-resources --deny --ibconnection /F./ib

# Снова разрешить
vrunner infobase lock-resources --allow --ibconnection /F./ib
```

```bash

```

### Аргументы

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `JOB` | - | Имя метаданных регламентного задания (**обязательный**) |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд).

### Примеры

```bash
vrunner infobase scheduled-job disable --ibconnection /F./ib ИзвлечениеТекста
vrunner infobase scheduled-job enable --ibconnection /F./ib ИзвлечениеТекста
```

## extensions

Работа с расширениями, уже установленными в базе.

```bash
vrunner infobase extensions <list | check | create | delete | set-options> [опции] [NAME]
```

> Общие опции всех подкоманд: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд).

### list

Выводит список установленных расширений в stdout: по умолчанию только имена, с `--verbose` - таблицу, с `--json` - массив JSON.

```bash
vrunner infobase extensions list [опции]
```

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-v`, `--verbose` | - | Таблица: имя, синоним, версия и параметры расширений |
| `--json` | - | JSON: имя, синоним, версия, хэш, параметры. Имеет приоритет над `--verbose` |

Чтобы в stdout не попадали строки лога, переведите лог в stderr ключом `log-output` (см. [Потоки вывода](../настройка/настройки#потоки-вывода)).

### check

Проверяет применимость установленных расширений без их загрузки. Без `NAME` проверяются все расширения. Если найдены проблемы применимости - код возврата 1.

```bash
vrunner infobase extensions check [опции] [NAME]
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `NAME` | - | Имя расширения (по умолчанию проверяются все) |

### create

Создаёт пустое расширение с заданным именем через Конфигуратор. Если расширение уже существует - ошибка; `--overwrite` пересоздаёт его. Конфигурация БД не обновляется - примените расширение командой `infobase update --target <NAME>`.

```bash
vrunner infobase extensions create [опции] <NAME>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `NAME` | - | Имя создаваемого расширения (**обязательный**) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--overwrite` | - | Пересоздать расширение, если оно уже существует |

### delete

Удаляет установленное расширение по имени. Если расширение не найдено - ошибка.

```bash
vrunner infobase extensions delete [опции] <NAME>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `NAME` | - | Имя удаляемого расширения (**обязательный**) |

### set-options

Изменяет параметры установленного расширения без его перезагрузки. Меняются только переданные параметры; хотя бы один обязателен. Значения - `true` или `false`.

```bash
vrunner infobase extensions set-options [опции] <NAME>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `NAME` | - | Имя расширения (**обязательный**) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--active` | - | Активность расширения |
| `--safe-mode` | - | Безопасный режим |
| `--unsafe-action-protection` | - | Защита от опасных действий |
| `--main-roles-for-all` | - | Использовать основные роли для всех пользователей (платформа 8.3.15+) |

### Примеры

```bash
# Список установленных расширений
vrunner infobase extensions list --ibconnection /F./ib

# JSON для скриптов (лог - в stderr)
VRUNNER_LOG_OUTPUT=stderr vrunner infobase extensions list --json --ibconnection /F./ib | jq '.[].имя'

# Проверить применимость всех расширений
vrunner infobase extensions check --ibconnection /F./ib

# Создать пустое расширение и применить его к БД
vrunner infobase extensions create --ibconnection /F./ib МоёРасширение
vrunner infobase update --target МоёРасширение --ibconnection /F./ib

# Удалить расширение
vrunner infobase extensions delete --ibconnection /F./ib МоёРасширение

# Включить безопасный режим и снять защиту от опасных действий
vrunner infobase extensions set-options --safe-mode true --unsafe-action-protection false --ibconnection /F./ib МоёРасширение
```
