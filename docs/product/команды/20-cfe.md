# cfe - Операции с расширениями

Сборка расширения из исходников в `.cfe` и разборка в исходники, загрузка в базу и выгрузка, сравнение, конвертация между форматами XML и 1С:EDT.

```bash
vrunner cfe <подкоманда> [опции] [аргументы]
```

Каталог исходников может быть как XML-дампом Конфигуратора, так и проектом 1С:EDT - формат определяется автоматически, см. [Исходники в формате 1С:EDT](./edt). Общие опции описаны на странице [Общие опции](./common-options).

Имя расширения - одно слово из букв, цифр и `_`, начинается с буквы или `_`. Проверка применимости установленных расширений и изменение их параметров - команды [`infobase extensions check` и `set-options`](./infobase#extensions).

## compile

Собирает расширение из исходников в файл `.cfe`. Без `--ibconnection` используется временная ИБ.

```bash
vrunner cfe compile [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | `VRUNNER_CFE_OUT` | Путь к создаваемому файлу `.cfe` (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | `VRUNNER_SRC` | Каталог исходников расширения (по умолчанию - текущий) |
| `--extension-name` | `VRUNNER_EXTENSION_NAME` | Имя расширения (по умолчанию - имя каталога исходников) |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [--settings](./common-options#файл-настроек).

```bash
# Имя расширения задано явно
vrunner cfe compile --ibcmd -s ./extensions/MyExtension/src --extension-name MyExtension ./build/MyExtension.cfe

# Имя расширения - из имени каталога (MyExtension)
vrunner cfe compile -s ./extensions/MyExtension ./build/MyExtension.cfe
```

## decompile

Разбирает расширение в исходники: из файла `.cfe` (он загружается во временную или указанную ИБ) либо напрямую из базы, если `--cfe-file` не задан - тогда расширение с именем `--extension-name` должно быть установлено в базе. Без `--cfe-file` и без `--ibconnection` команда завершается ошибкой.

```bash
vrunner cfe decompile [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Каталог для выгрузки исходников (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--cfe-file` | `VRUNNER_CFE_FILE` | Путь к файлу `.cfe`. Если не задан - исходники выгружаются из базы `--ibconnection` |
| `--extension-name` | `VRUNNER_EXTENSION_NAME` | Имя расширения (обязательна) |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [--settings](./common-options#файл-настроек).

```bash
# Разобрать cfe в XML-исходники
vrunner cfe decompile --ibcmd --cfe-file ./build/MyExtension.cfe --extension-name MyExtension ./extensions/MyExtension/src

# Выгрузить исходники установленного расширения из базы
vrunner cfe decompile --extension-name MyExtension --ibconnection /FD:/bases/work ./extensions/MyExtension/src
```

## load

Загружает расширение в базу из каталога исходников или файла `.cfe` (источник с расширением `.cfe` считается файлом, иначе - каталогом) напрямую движком - без сборки `.cfe` во временной базе, поэтому работает и для расширений, которые компилируются только поверх основной конфигурации. Без `--ibconnection` используется файловая ИБ `build/ib`.

После загрузки конфигурация БД расширения обновляется (`UpdateDBCfg` / `config apply`), затем применяются свойства расширения. Флаг `--no-update-db` отключает обновление; свойства при этом не изменяются.

```bash
vrunner cfe load [опции] [SRC]
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `SRC` | - | Каталог исходников или файл `.cfe` (по умолчанию - текущий каталог; в файле настроек - ключ `src`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--extension-name` | `VRUNNER_EXTENSION_NAME` | Имя расширения в базе (по умолчанию - имя каталога или файла источника) |
| `--safe-mode` | - | Включить безопасный режим |
| `--active` | - | Сделать расширение активным |
| `--unsafe-action-protection` | - | Включить защиту от опасных действий |
| `--used-in-rib` | - | Используется в РИБ (только `--ibcmd`) |
| `--scope-infobase` | - | Область действия - информационная база, а не разделитель данных (только `--ibcmd`) |
| `--increment` | - | Инкрементальная загрузка: грузятся только файлы, изменённые с прошлого запуска (только для каталога исходников) |
| `--no-update-db` | - | Не обновлять конфигурацию БД после загрузки |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [обновление БД](./common-options#обновление-конфигурации-бд), [формат исходников](./common-options#формат-исходников), [--settings](./common-options#файл-настроек).

`--increment` ведёт индекс изменений каталога исходников так же, как [`cf load`](./cf#load); для EDT-исходников - см. [Инкрементальная загрузка из EDT](./edt#инкрементальная-загрузка-из-edt).

Свойства расширения устанавливаются по-разному:

- **Конфигуратор** - обработкой в 1С:Предприятии при каждой загрузке: безопасный режим и защита от опасных действий выключены, если флаги не переданы; активность меняется только при `--active`. `--used-in-rib` и `--scope-infobase` не поддерживаются (предупреждение).
- **ibcmd** - средствами `ibcmd`, только если передан хотя бы один флаг свойств; не переданные свойства получают значения по умолчанию (активно, без безопасного режима и защиты, не в РИБ, область - ИБ).

```bash
# Загрузить из исходников через ibcmd
vrunner cfe load --ibcmd --ibconnection /F./ib --extension-name MyExtension ./extensions/MyExtension/src

# Загрузить cfe-файл с безопасным режимом
vrunner cfe load --ibconnection /F./ib --safe-mode ./MyExtension.cfe
```

## unload

Выгружает расширение из базы в файл `.cfe`. Без `--ibconnection` используется файловая ИБ `build/ib`.

```bash
vrunner cfe unload [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Путь к создаваемому файлу `.cfe` (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--extension-name` | `VRUNNER_EXTENSION_NAME` | Имя расширения в базе (обязательна) |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [--settings](./common-options#файл-настроек).

```bash
vrunner cfe unload --ibconnection /F./ib --extension-name MyExtension ./backup/MyExtension.cfe
```

## compare

Сравнивает два файла `.cfe` или файл `.cfe` с расширением в базе и сохраняет отчёт `compare_report_<тип>_<дата_время>.<формат>` в каталог `--report-dir`. Только Конфигуратор. Без `--first-cfe` сравнивается расширение из базы - `--ibconnection` обязательна; при сравнении двух файлов без `--ibconnection` используется временная ИБ.

```bash
vrunner cfe compare [опции]
```

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--extension-name` | - | Имя расширения (обязательна) |
| `--second-cfe` | - | Второй файл `.cfe` - с чем сравниваем (обязательна) |
| `--first-cfe` | - | Первый файл `.cfe`; если не задан - расширение из базы |
| `--report-dir` | - | Каталог отчёта (по умолчанию - текущий) |
| `--report-type` | - | `Full` (по умолчанию) или `Brief` |
| `--report-format` | - | `txt` (по умолчанию) или `mxl` |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [--settings](./common-options#файл-настроек).

```bash
vrunner cfe compare --extension-name MyExtension --first-cfe ./old/MyExtension.cfe --second-cfe ./new/MyExtension.cfe --report-dir ./reports
```

## convert

Конвертирует каталог исходников расширения между форматами 1С:EDT и XML-дампа Конфигуратора утилитой `1cedtcli`. Формат источника определяется автоматически, результат пишется в противоположном формате. Если в каталоге нет маркеров ни одного формата или найдено несколько вложенных EDT-проектов - ошибка.

```bash
vrunner cfe convert [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Каталог результата (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | `VRUNNER_SRC` | Каталог исходников (по умолчанию - текущий) |

Общие опции: [EDT](./edt#опции), [--settings](./common-options#файл-настроек).

```bash
# EDT-проект расширения → XML-дамп
vrunner cfe convert -s ./edt-extension ./build/xml

# XML-дамп → EDT-проект
vrunner cfe convert -s ./build/xml ./edt-extension
```
