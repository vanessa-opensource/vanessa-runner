# epf - Операции с внешними обработками

Команды `epf` собирают, разбирают и конвертируют внешние обработки (`.epf`) и внешние отчёты (`.erf`).

```bash
vrunner epf <подкоманда> [опции] [аргументы]
```

`compile` и `decompile` выполняются Конфигуратором. Если `--ibconnection` не указана, создаётся временная файловая ИБ; флаг `--ibcmd` влияет только на способ её создания. Исходники принимаются и выгружаются как в XML-дампе Конфигуратора, так и в формате 1С:EDT (опция `--src-format`, см. [Исходники в формате 1С:EDT](./edt)).

## compile

Собирает внешние обработки и отчёты из исходников. Тип объекта и расширение результата определяются по корневому тегу XML: `ExternalDataProcessor` → `.epf`, `ExternalReport` → `.erf`.

```bash
vrunner epf compile [опции] [SRC]
```

Без `--recursive` `SRC` - каталог одного объекта с корневым `<Имя>.xml`; с `--recursive` собираются все объекты, найденные в подкаталогах. Из проекта внешних объектов 1С:EDT собираются все его объекты. По умолчанию результат сохраняется рядом с исходниками.

### Аргументы

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `SRC` | - | Каталог исходников (по умолчанию - текущий; в файле настроек - ключ `src`) |

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-R`, `--recursive` | - | Рекурсивный поиск обработок и отчётов в подкаталогах |
| `--out` | - | Каталог для собранных файлов |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [файл настроек](./common-options#файл-настроек).

### Примеры

```bash
# Собрать одну обработку (результат - ./src/epf/МояОбработка.epf)
vrunner epf compile --ibcmd ./src/epf/МояОбработка

# Рекурсивно собрать все обработки и отчёты в каталог build/epf
vrunner epf compile -R --out ./build/epf --ibcmd ./src/epf

# Собрать в существующей базе через Конфигуратор
vrunner epf compile --ibconnection /F./ib --v8version 8.3.24 ./src/epf/МояОбработка

# Собрать все объекты проекта 1С:EDT
vrunner epf compile --src-format edt --out ./build/epf ./edt/ВнешниеОбработки
```

## decompile

Разбирает файл `.epf`/`.erf` или каталог с такими файлами в исходники. Для каждого файла создаётся подкаталог с его именем: по умолчанию рядом с файлом, с `--out` - в указанном каталоге. С `--src-format edt` (или если `--out` - существующий EDT-проект) исходники импортируются в проект внешних объектов 1С:EDT.

```bash
vrunner epf decompile [опции] <SRC>
```

### Аргументы

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `SRC` | - | Файл `.epf`/`.erf` или каталог с ними (**обязательный**; в файле настроек - ключ `src`) |

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-R`, `--recursive` | - | Рекурсивный поиск файлов `.epf`/`.erf` в подкаталогах (если `SRC` - каталог) |
| `--out` | - | Каталог для разобранных исходников |

> Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [файл настроек](./common-options#файл-настроек).

### Примеры

```bash
# Разобрать один файл (исходники - в ./build/МойОтчёт/)
vrunner epf decompile --ibcmd ./build/МойОтчёт.erf

# Разобрать все файлы каталога рекурсивно в src/epf
vrunner epf decompile -R --out ./src/epf --ibcmd ./build/epf

# Разобрать в проект 1С:EDT
vrunner epf decompile --src-format edt --out ./edt/ВнешниеОбработки ./build/МояОбработка.epf
```

## convert

Конвертирует внешние обработки и отчёты между форматами 1С:EDT и XML Конфигуратора утилитой `1cedtcli` - без сборки `.epf` и без информационной базы. Направление определяется по каталогу `--src`: EDT-проект выгружается в XML (`OUT/ExternalDataProcessors/`, `OUT/ExternalReports/`, по одному `<Имя>.xml` на объект), XML-дампы импортируются в EDT-проект.

```bash
vrunner epf convert [опции] <OUT>
```

### Аргументы

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Каталог результата в противоположном формате (**обязательный**; в файле настроек - ключ `out`) |

### Опции

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | `VRUNNER_SRC` | Каталог источника: EDT-проект или XML-дампы (по умолчанию - текущий каталог) |

> Общие опции: [EDT](./edt), [файл настроек](./common-options#файл-настроек).

### Примеры

```bash
# EDT → XML
vrunner epf convert --src ./edt/ВнешниеОбработки --edt-version 2025.2 ./build/xml

# XML → EDT (обратно)
vrunner epf convert --src ./build/xml ./edt/ВнешниеОбработки
```
