# cf - Операции с конфигурацией

Сборка конфигурации из исходников и разборка в исходники, загрузка в базу и выгрузка, объединение, обновление на поддержке, сравнение, файл поставки, конвертация между форматами XML и 1С:EDT.

```bash
vrunner cf <подкоманда> [опции] [аргументы]
```

Каталог исходников везде может быть как XML-дампом Конфигуратора, так и проектом 1С:EDT - формат определяется автоматически, см. [Исходники в формате 1С:EDT](./edt). Общие опции описаны на странице [Общие опции](./common-options).

## compile

Собирает конфигурацию из исходников в файл `.cf`. Без `--ibconnection` используется временная ИБ.

```bash
vrunner cf compile [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | `VRUNNER_CF_OUT` | Путь к создаваемому файлу `.cf` (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | `VRUNNER_SRC` | Каталог исходников (по умолчанию - текущий) |
| `--list` | - | Файл со списком файлов для выборочной загрузки (по одному пути на строку) |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [--settings](./common-options#файл-настроек).

```bash
# Сборка через ibcmd во временной базе
vrunner cf compile --ibcmd -s ./src ./build/MyApp.cf

# Сборка через Конфигуратор в указанной базе
vrunner cf compile -s ./src --ibconnection /FD:/bases/MyProject --v8version 8.3.24 ./build/MyApp.cf
```

## decompile

Разбирает конфигурацию в исходники: из файла `.cf` (он загружается во временную или указанную ИБ) либо напрямую из базы, если `--cf-file` не задан. Без `--cf-file` и без `--ibconnection` команда завершается ошибкой.

```bash
vrunner cf decompile [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Каталог для выгрузки исходников (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--cf-file` | `VRUNNER_CF_FILE` | Путь к файлу `.cf`. Если не задан - исходники выгружаются из базы `--ibconnection` |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [формат исходников](./common-options#формат-исходников), [--settings](./common-options#файл-настроек).

```bash
# Разобрать cf в XML-исходники
vrunner cf decompile --ibcmd --cf-file ./build/MyApp.cf ./src

# Выгрузить исходники из существующей базы в формате EDT
vrunner cf decompile --ibconnection /FD:/bases/work --src-format edt ./edt-project
```

## load

Загружает конфигурацию в базу из каталога исходников или файла `.cf` (источник с расширением `.cf` считается файлом, иначе - каталогом). После загрузки конфигурация БД обновляется (`UpdateDBCfg` / `config apply`); флаг `--no-update-db` отключает обновление.

```bash
vrunner cf load [опции] [SRC]
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `SRC` | - | Каталог исходников или файл `.cf` (по умолчанию - текущий каталог; в файле настроек - ключ `src`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--list` | - | Файл со списком файлов для выборочной загрузки (только для каталога исходников) |
| `--increment` | - | Инкрементальная загрузка: грузятся только файлы, изменённые с прошлого запуска (только для каталога исходников) |
| `--no-update-db` | - | Не обновлять конфигурацию БД после загрузки |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [ibcmd](./common-options#конфигуратор-или-ibcmd), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [обновление БД](./common-options#обновление-конфигурации-бд), [формат исходников](./common-options#формат-исходников), [--settings](./common-options#файл-настроек).

`--increment` ведёт индекс изменений каталога исходников (по умолчанию в `<temp>/vanessa-runner/cache`, настройка `increment.cache-dir`). Первый запуск, удаление файлов и изменения, требующие полной загрузки, выполняются полной загрузкой; если изменений нет, загрузка пропускается. Особенности для EDT-исходников: [Инкрементальная загрузка из EDT](./edt#инкрементальная-загрузка-из-edt).

```bash
# Загрузить исходники и обновить конфигурацию БД
vrunner cf load --ibconnection /F./ib ./src

# Загрузить cf-файл без обновления конфигурации БД
vrunner cf load --ibconnection /F./ib --no-update-db ./build/MyApp.cf

# Инкрементальная загрузка через ibcmd
vrunner cf load --ibcmd --ibconnection /F./ib --increment ./src
```

## merge

Объединяет конфигурацию базы с файлом `.cf` по файлу настроек объединения (`/MergeCfg`). Только Конфигуратор; `--ibconnection` обязательна.

```bash
vrunner cf merge [опции]
```

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | - | Файл `.cf` для объединения (обязательна) |
| `--merge-settings` | - | Файл настроек объединения (обязательна) |
| `--enable-support` | - | Поставить конфигурацию на поддержку |
| `--disable-support` | - | Снять конфигурацию с поддержки |
| `--IncludeObjectsByUnresolvedRefs` | - | Включить в объединение объекты с неразрешёнными ссылками |
| `--ClearUnresolvedRefs` | - | Очищать неразрешённые ссылки |
| `--force` | - | Объединять при наличии предупреждений |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [--settings](./common-options#файл-настроек).

```bash
# Первичная постановка на поддержку дистрибутивом поставщика
vrunner cf merge -s ./vendor/BSP.cf --merge-settings ./merge-settings.xml --enable-support --ibconnection /F./ib
```

## vendor-update

Обновляет конфигурацию, находящуюся на поддержке, файлом обновления `.cfu` или полным дистрибутивом `.cf` поставщика (`/UpdateCfg`) с сохранением доработок по правилам поддержки. После обновления конфигурация БД обновляется (`UpdateDBCfg`); флаг `--no-update-db` отключает обновление. Только Конфигуратор; `--ibconnection` обязательна.

Конфигурация базы должна уже быть на поддержке, а файл - содержать другую версию поставщика, иначе Конфигуратор откажет с ошибкой «Файл не содержит доступных обновлений». Первичная постановка на поддержку - `cf merge --enable-support`.

```bash
vrunner cf vendor-update [опции]
```

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | - | Файл `.cfu` или `.cf` поставщика (обязательна). В имени файла допустим шаблон `$version`: из подходящих файлов берётся старшая версия |
| `--update-settings` | - | Файл настроек объединения |
| `--IncludeObjectsByUnresolvedRefs` | - | Включить в объединение объекты с неразрешёнными ссылками |
| `--ClearUnresolvedRefs` | - | Очищать неразрешённые ссылки |
| `--DumpListOfTwiceChangedProperties` | - | Вывести список дважды изменённых свойств в файл служебных сообщений |
| `--force` | - | Обновлять при наличии предупреждений |
| `--no-update-db` | - | Не обновлять конфигурацию БД после обновления |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [обновление БД](./common-options#обновление-конфигурации-бд), [--settings](./common-options#файл-настроек).

```bash
# Обновить файлом поставщика
vrunner cf vendor-update -s ./updates/1cv8.cfu --ibconnection /F./ib --force

# Шаблон $version: из 1cv8_8.3.24.100.cfu и 1cv8_8.3.25.50.cfu будет выбран 1cv8_8.3.25.50.cfu
vrunner cf vendor-update -s './updates/1cv8_$version.cfu' --ibconnection /F./ib --force
```

## compare

Сравнивает два файла `.cf` или файл `.cf` с конфигурацией базы и сохраняет отчёт `compare_report_<тип>_<дата_время>.<формат>` в каталог `--report-dir`. Только Конфигуратор. Без `--first-cf` сравнивается конфигурация базы - `--ibconnection` обязательна; при сравнении двух файлов без `--ibconnection` используется временная ИБ.

```bash
vrunner cf compare [опции]
```

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `--second-cf` | - | Второй файл `.cf` - с чем сравниваем (обязательна) |
| `--first-cf` | - | Первый файл `.cf`; если не задан - конфигурация базы |
| `--report-dir` | - | Каталог отчёта (по умолчанию - текущий) |
| `--report-type` | - | `Full` (по умолчанию) или `Brief` |
| `--report-format` | - | `txt` (по умолчанию) или `mxl` |

Общие опции: [подключение к ИБ](./common-options#подключение-к-информационной-базе), [платформа](./common-options#платформа), [СУБД](./common-options#опции-субд), [--settings](./common-options#файл-настроек).

```bash
# Сравнить два файла
vrunner cf compare --first-cf ./old/App.cf --second-cf ./new/App.cf --report-dir ./reports

# Сравнить конфигурацию базы с файлом, краткий отчёт
vrunner cf compare --second-cf ./vendor/BSP.cf --ibconnection /F./ib --report-type Brief
```

## convert

Конвертирует каталог исходников между форматами 1С:EDT и XML-дампа Конфигуратора утилитой `1cedtcli`. Формат источника определяется автоматически, результат пишется в противоположном формате. Если в каталоге нет маркеров ни одного формата или найдено несколько вложенных EDT-проектов - ошибка.

```bash
vrunner cf convert [опции] <OUT>
```

| Аргумент | Переменная окружения | Описание |
|----------|---------------------|----------|
| `OUT` | - | Каталог результата (обязателен; в файле настроек - ключ `out`) |

| Опция | Переменная окружения | Описание |
|-------|---------------------|----------|
| `-s`, `--src` | `VRUNNER_SRC` | Каталог исходников (по умолчанию - текущий) |

Общие опции: [EDT](./edt#опции), [--settings](./common-options#файл-настроек).

```bash
# EDT-проект → XML-дамп
vrunner cf convert -s ./edt-project ./build/xml

# XML-дамп → EDT-проект, увеличенный таймаут 1cedtcli
vrunner cf convert -s ./build/xml --edt-timeout 5400 ./edt-project
```
