# Первые шаги

## Синтаксис команд

```bash
vrunner <группа> <подкоманда> [опции] [аргумент]
```

Опции указываются до позиционного аргумента:

```bash
# Собрать конфигурацию из исходников
vrunner cf compile --src ./src ./build/MyApp.cf

# Разобрать cf-файл в исходники
vrunner cf decompile --cf-file ./build/MyApp.cf ./src

# Создать базу и загрузить в неё конфигурацию
vrunner infobase init --src ./build/MyApp.cf --ibconnection /FD:/bases/MyApp

# Запустить xUnit-тесты
vrunner test xunit --ibconnection /FD:/bases/MyApp ./tests
```

Список групп и подкоманд - в [справочнике команд](../команды/cf), общие для многих команд опции (подключение к базе, `--ibcmd`, платформа, СУБД) - на странице [Общие опции](../команды/common-options).

## Справка

Справка выводится флагом `--help` на любом уровне:

```bash
vrunner --help
vrunner cf --help
vrunner cf compile --help
```

Формы `vrunner help cf` и `vrunner cf help` не работают.

## База по умолчанию

Если `--ibconnection` не указан, `infobase init` создаёт файловую базу в каталоге `build/ib` текущего каталога, а команды обслуживания базы (`infobase update`, `infobase extensions`, `cfe load`) работают с ней же. Команды сборки и разборки (`cf compile`, `cf decompile`, `cfe compile`, `epf compile`) без базы создают временную. Подробнее: [Общие опции](../команды/common-options).

## Настройки проекта

Повторяющиеся опции выносятся в файл `autumn-properties.json` в каталоге проекта:

```json
{
  "vrunner": {
    "ibconnection": "/FD:/bases/MyApp",
    "v8version": "8.3.24",
    "db-user": "Администратор"
  }
}
```

Значение из командной строки сильнее переменной окружения, а та - сильнее файла. Подробнее: [Файл настроек](../настройка/настройки), [Переменные окружения](../настройка/переменные-окружения).

## Пример для CI

```bash
# 1. Создать базу из cf-файла (по умолчанию - build/ib)
vrunner infobase init --src ./build/MyApp.cf

# 2. Обновить конфигурацию базы из исходников
vrunner infobase update --src ./src

# 3. Прогнать тесты с отчётом JUnit
vrunner test xunit \
  --ibconnection /F./build/ib \
  --report-format junit \
  --report-path ./build/reports/junit.xml \
  ./tests
```
