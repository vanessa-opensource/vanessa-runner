# Установка

## Требования

- [OneScript](https://oscript.io/) версии 2.0 и выше
- Платформа 1С:Предприятие 8.3 (для работы с базами)

## Установка через opm

```bash
opm install vanessa-runner
```

После установки команда `vrunner` будет доступна глобально.

## Установка из исходников

```bash
git clone https://github.com/vanessa-opensource/vanessa-runner.git
cd vanessa-runner
opm install -l
```

## Проверка установки

```bash
vrunner --version
```

Ожидаемый вывод:

```
vanessa-runner 3.x.x
```

## Обновление

```bash
opm install -u vanessa-runner
```

> [!WARNING]
> **На Windows запущенный MCP-сервер блокирует обновление.**
> Если vanessa-runner используется как [MCP-сервер](../mcp), запущенный из
> каталога установки, его процесс держит загруженными нативные компоненты
> (например `change-indexer`). На Windows такую загруженную DLL нельзя
> перезаписать, поэтому `opm install -u` (и переустановка пакета) завершится
> ошибкой вида `Access to the path '...\1script_change_indexer.dll' is denied`.
>
> Перед обновлением остановите MCP-сервер: отключите его в IDE/клиенте либо
> завершите процесс `oscript`/`vrunner-mcp`, который запущен из каталога установки.
> После `opm install -u` клиент переподключит сервер уже с обновлённой версией.
> Чтобы не сталкиваться с этим, запускайте MCP-сервер из копии в репозитории
> (`oscript src/mcp.os` с рабочим каталогом проекта), а не из каталога установки.

## Установка зависимостей для разработки

```bash
opm install
```

Зависимости устанавливаются в папку `oscript_modules/`.
