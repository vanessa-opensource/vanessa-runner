# Установка

## Требования

- [OneScript](https://oscript.io/) 2.0.0 и выше.
- Платформа 1С:Предприятие 8.3 - для команд, работающих с базами, конфигуратором, `ibcmd` и `rac`.

## Установка через opm

```bash
opm install vanessa-runner
```

Вместе с пакетом ставятся команды `vrunner` (синоним `vanessa-runner`) и `vrunner-mcp` ([MCP-сервер](../mcp)); они доступны из любого каталога, как и `oscript`.

Проверка:

```bash
vrunner --version
```

Команда выводит номер установленной версии.

## Установка vanessa-add

Для `test xunit` и `test vanessa` нужны обработки [Vanessa-ADD](https://github.com/vanessa-opensource/vanessa-automation-driven-development) (`xddTestRunner.epf`, `bddRunner.epf`):

```bash
opm install add
```

vrunner находит пакет в каталоге `lib/add` рядом с OneScript; этот же каталог подставляется в макрос `$addRoot`. Обработки из другого места указываются опциями `--pathxunit` и `--bddrunner-path`.

## Обновление

```bash
opm update vanessa-runner
```

> [!WARNING]
> На Windows запущенный [MCP-сервер](../mcp) держит загруженной нативную библиотеку из каталога установки, и обновление завершается ошибкой `Access to the path '...\1script_change_indexer.dll' is denied`. Перед обновлением остановите сервер: отключите его в клиенте или завершите процесс `oscript`/`vrunner-mcp`, запущенный из каталога установки.

## Установка из исходников

```bash
git clone https://github.com/vanessa-opensource/vanessa-runner.git
cd vanessa-runner
opm install -l
opm build .
opm install -f vanessa-runner-*.ospx
```

`opm install -l` ставит зависимости в `oscript_modules/`, `opm build .` собирает пакет и попутно компилирует служебные обработки из `epf/` (нужна платформа 1С). Без установки пакета vrunner запускается прямо из каталога репозитория: `oscript src/main.os <команда>`; служебные обработки в этом случае собираются командой `oscript src/main.os epf compile -R epf`.
