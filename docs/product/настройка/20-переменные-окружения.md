# Переменные окружения

Часть опций и аргументов можно задать переменными окружения - удобно в CI, где параметры подключения нежелательно передавать в командной строке. Переменная опции показана в справке команды (`vrunner <команда> --help`, пометка `env $VRUNNER_...`).

Переменная окружения слабее аргумента командной строки и сильнее [файла настроек](./настройки). Флаги включаются значением `true`.

## Подключение к ИБ

| Переменная | Опция | Описание |
|------------|-------|----------|
| `VRUNNER_IBCONNECTION` | `--ibconnection` | Строка подключения (`/F<путь>` или `/S<сервер>\<база>`) |
| `VRUNNER_DBUSER` | `--db-user` | Пользователь информационной базы |
| `VRUNNER_DBPWD` | `--db-pwd` | Пароль пользователя ИБ |

## Платформа

| Переменная | Опция | Описание |
|------------|-------|----------|
| `VRUNNER_V8VERSION` | `--v8version` | Версия платформы 1С |
| `VRUNNER_UCCODE` | `--uccode` | Код разрешения |
| `VRUNNER_LANGUAGE` | `--language` | Язык платформы |
| `VRUNNER_LOCALE` | `--locale` | Язык сеанса (локаль) |

## СУБД

| `VRUNNER_DBMS_PWD` | `--dbms-pwd` | Пароль СУБД |

| `VRUNNER_ADDITIONAL` | `--additional` | Дополнительные параметры запуска платформы (также `run designer`) |
| `VRUNNER_IBSRV` | `--ibsrv` | Запускать через автономный сервер ibsrv (только файловые ИБ) |
| `VRUNNER_IBSRV_DIRECT` | `--ibsrv-direct` | Прямое соединение с ibsrv вместо WS |

| `VRUNNER_IBSRV_ATTACH` | `--ibsrv-attach` | Подключиться к уже запущенному ibsrv |
| `VRUNNER_IBSRV_PORT` | `--ibsrv-port` | Порт ibsrv |

## Отчёты и покрытие

| Переменная | Опция | Описание |
|------------|-------|----------|
| `VRUNNER_REPORT_PATH` | `--report-path` | Куда выгрузить отчёт ([подробнее](../команды/reports)) |
| `VRUNNER_COVERAGE_REPORT` | `--coverage-report` | Файл отчёта покрытия; задан - покрытие включено ([подробнее](../команды/coverage)) |
| `VRUNNER_COVERAGE_FORMAT` | `--coverage-format` | Формат отчёта покрытия |
| `VRUNNER_COVERAGE_SRC` | `--coverage-src` | Каталог исходников конфигурации для сопоставления модулей |
| `VRUNNER_COVERAGE_SERVER` | `--coverage-server` | Сервер отладки `[хост:]порт` |
| `VRUNNER_COVERAGE_DBGS` | `--coverage-dbgs` | Путь к `dbgs` |
| `VRUNNER_COVERAGE_ALIAS` | `--coverage-alias` | Имя ИБ для сессии отладки |
| `VRUNNER_COVERAGE_DEBUG_PWD` | `--coverage-debug-pwd` | Пароль сервера отладки |
| `VRUNNER_COVERAGE_SKIP_LINES` | `--coverage-skip-lines` | Не рассчитывать покрываемые строки |

Устаревшие переменные отчётов продолжают работать: `VRUNNER_JUNITPATH` (`--junitpath`), `VRUNNER_ALLURE_RESULTS` (`--allure-results`), `VRUNNER_REPORTSXUNIT` (`--reportsxunit`), `VRUNNER_YAXUNIT_REPORT` (`--report` в `test yaxunit`), `VRUNNER_EDT_REPORT` (`--report` в `validate edt`). Замена - `--report-format` и `--report-path`. Формат отчёта переменной окружения не имеет.

## Настройки и лог

| Переменная | Опция | Описание |
|------------|-------|----------|
| `VRUNNER_SETTINGS` | `--settings` | Путь к файлу настроек (JSON); файл обязан существовать |
| `VRUNNER_LOG_OUTPUT` | - | Куда писать лог: `stdout` (по умолчанию) или `stderr`, см. [Потоки вывода](./настройки#потоки-вывода) |

## Ключи файла настроек через окружение

Любой ключ файла настроек можно задать переменной окружения: имя ключа в верхнем регистре, точки заменены на `_`. Так задаются опции, у которых нет своей переменной, например флаг `--ibcmd`:

```bash
export VRUNNER_IBCMD=true                       # vrunner.ibcmd - для всех команд
export VRUNNER_CF_COMPILE_OUT=./build/App.cf    # vrunner.cf.compile.out
```

Такая переменная действует, только если тот же ключ не задан ни в одном файле настроек: значение из файла сильнее. Для опций с дефисом в имени (`db-user`) используйте их собственные переменные.

## Пример для CI

```bash
export VRUNNER_IBCONNECTION="/S1c-server\MyBase"
export VRUNNER_DBUSER=Admin
export VRUNNER_DBPWD=$SECRET_IB_PWD
export VRUNNER_V8VERSION=8.3.24
export VRUNNER_IBCMD=true
export VRUNNER_DBMS_TYPE=PostgreSQL
export VRUNNER_DBMS_SERVER=pg.internal
export VRUNNER_DBMS_BASE=my_db
export VRUNNER_DBMS_USER=postgres
export VRUNNER_DBMS_PWD=$SECRET_PG_PWD

vrunner infobase update --src ./build/MyApp.cf
vrunner test xunit --report-format junit --report-path ./build/reports/junit.xml ./tests
```
