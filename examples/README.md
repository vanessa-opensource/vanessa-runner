# Примеры

Однострочные сценарии для CI и скриптов проекта: одна и та же команда в `.bat` (Windows) и `.sh` (Linux/macOS).
Полное описание команд и опций - в [документации](https://autumn-library.github.io/vanessa-runner).

| Файл | Что делает |
|------|-----------|
| `compile` | сборка конфигурации, расширения и обработок из исходников |
| `decompile` | разборка `.cf`, `.cfe`, `.epf` в исходники |
| `init` | создание базы и загрузка конфигурации |
| `update` | загрузка конфигурации и обновление структуры БД |
| `update-dev` | то же инкрементально, только изменённые файлы |
| `loadrepo` | загрузка из хранилища 1С |
| `runafterupdate` | запуск обработки после обновления |
| `xunit` | xUnit-тесты с отчётом jUnit |
| `vanessa` | BDD-сценарии Vanessa-ADD с настройками из `vb-conf.json` |
| `autumn-properties.json` | файл настроек проекта: общие значения опций вместо повторения в каждой команде |

`autumn-properties.json` подхватывается из рабочего каталога автоматически, ключ `$schema` даёт подсказки и проверку ключей в редакторе.
